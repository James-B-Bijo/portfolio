# Editing BBJ

## Add a project (no new page needed)
1. Place images in the repository root alongside index.html.
2. Open content.js in your editor.
3. Duplicate one object in the projects list. Use a unique id, your title, category, description, drawing/image path, status, location, year and credits. A render is optional (use null when absent).
4. For extra images set gallery to [{"src": "my-detail.jpg", "caption": "Detail"}].
5. Save and refresh. The archive and previous/next links update automatically. Share project.html?id=YOUR-ID.

All content is plain HTML/CSS/JavaScript. No build or subscription required.

## Contact
Set profile.email in content.js. With an email, enquiries open an email draft for the visitor to send. Without it, the form downloads a text file. It never pretends to send a message.

## Other pages
Edit about.html and bijo-b-james.html for your biography. Edit practice.html for drawings/process. Update the repeated header/footer in each HTML file when changing navigation. style.css controls spacing, colour and responsive layouts. site.js contains interactions.

Current assets are temporary samples, not final project records. Replace the sample notice on index.html and practice.html when final work is added. Confirm credits and privacy wording before publishing.
